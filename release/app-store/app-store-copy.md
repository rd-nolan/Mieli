## Description

### en-US

Mieli is a simple, native Markdown editor for Mac. Capture ideas, shape them into clear notes, and keep your workspace close at hand.

Open a Markdown file or a folder and start writing. Mieli keeps related notes together in a clean file tree, gives every document its own tab, and stays out of the way while you think.

Highlights:

- Open individual `.md` and `.markdown` files or recursive Markdown folders.
- Edit with a focused native Mac interface and familiar tabs.
- Create a new document whenever an idea arrives.
- Save changes automatically and save to a new location when needed.
- Keep your recent files close at hand.
- Notice external file changes before they overwrite your work.
- Switch between English and Simplified Chinese.

Mieli is made for thoughtful writing: lightweight, local, and easy to return to.

### zh-Hans

Mieli 是一款简洁、原生的 Mac Markdown 编辑器。随手记下灵感，把想法整理成清晰的笔记，让工作区始终触手可及。

打开 Markdown 文件或文件夹即可开始写作。Mieli 用清晰的文件树整理相关笔记，为每篇文档提供独立标签页，在你思考时保持安静、不打扰。

主要功能：

- 打开单个 `.md`、`.markdown` 文件，或递归打开 Markdown 文件夹。
- 使用专为 Mac 打造的专注界面和熟悉的标签页。
- 灵感出现时，随时新建文档。
- 自动保存更改，也可以将文档保存到新位置。
- 随时访问最近打开的文件。
- 外部文件发生变化时及时提醒，避免覆盖你的编辑内容。
- 支持英文和简体中文界面切换。

Mieli 为认真写作而生：轻量、本地、打开就能继续。
